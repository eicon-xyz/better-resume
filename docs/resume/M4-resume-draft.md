# 简历草稿（M4 语音里程碑）

> D14 硬规则：每个里程碑结束更新一次简历草稿。
> 口径原则：**只写已经跑通、可演示的东西**；M4 的对外物 = 按住麦克风说答案 → 实时上屏 → 提交；
> 点一下题目就能听播报。真机讯飞与真实浏览器的人工验证尚未做，这里也如实标注。

## 1. 本阶段新增条目（有执行证据）

- **实时转写句池归并算法（D16 亮点③，旧项目"独家亮点"的最后一块）**：把原 Java 内部类
  AstTranscriptionAssembler 移植为 Python 纯函数模块 —— pgs=apd 追加 / pgs=rpl 按 rg 删区间 /
  **无 pgs 包按时间重叠度(≥0.6)+文本演化(公共前缀≥0.8 或互相包含)判定同段** / 尾缀合并（最小 2 字，
  单字重叠不吞正文）/ final 提交；输出三级文本（committed / live / display）+ 单调 revision。
  22 例逐分支单测，0.03s 跑完。
- **讯飞 AST WebSocket 适配器**：HmacSHA1 签名 URL、1280B/40ms 推流节拍、cn.st.rt[].ws[].cw[].w 解析、
  有界重连（连接结束即计一次掉线、预算按通道生命周期）、失败归一进 M3 的韧性三态；
  用**本地假 WS 服务端**做契约测试（10 例），真机验证待凭据。
- **WS 一次性票据（D11）**：HTTP 换票 → WS 握手消费，Redis 用两行 Lua 实现原子"取并删"
  （Redis 6.0 没有 GETDEL）；票复用/过期/未登录/并发第二路（4409）都有用例。
- **TTS 播报**：edge-tts 真合成（实测 25.2 KB mp3、MPEG 帧同步头）+ 内容寻址缓存
  （同文本同音色只合成一次，跨请求命中）+ 单例播放器（手势解锁 autoplay、canplaythrough 3s 超时、卸载 revoke）；
  TTS 作为独立 Stage 接入 M3 的韧性链（单飞/熔断/超时/回放），失败返回 503/504 而不是静默播空音频。
- **浏览器端音频链路**：AudioWorklet（回退 ScriptProcessor）→ 16k 单声道 Int16 → 40ms/1280B 切片 →
  WS 上行；连接前 24 帧队列 + 丢帧计数、内容去重、有界重连、停止时 flush 尾帧并释放麦克风轨道。
- **D15「一个通道两个消费方、一个播放器」**：面试答案框与对话输入框共用一份三级文本 store，
  合并规则保证**转写永远不覆盖候选人手写的内容**（只在"输入框为空或已是前缀"时自动追加，
  否则只提示"有新的转写"）；题目卡片一个"朗读"按钮走同一个播放器。
