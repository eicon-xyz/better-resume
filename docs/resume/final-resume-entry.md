# 简历条目（BetterResume 项目经历）

BetterResume—AI 模拟面试平台 https://github.com/eicon-xyz/better-resume
技术栈： Python FastAPI SQLAlchemy PostgreSQL Redis WebSocket SSE React Docker
项目简介： 上传简历、AI 出题、语音与文字答题、评分追问、报告雷达图与 AI 对话的全链路模拟面试平台，后端、前端与部署一人独立完成。

• 采用自研韧性中间件统一收口全部模型调用，内置超时、熔断、并发隔离和令牌桶限流，解决 AI 调用散落在业务代码里一处抖动全链雪崩的问题，24 并发流式压测 48 次请求零失败。

• 用两套显式状态机管理会话生命周期与答题流程，把追问裁决做成 78 例判定表的纯函数，解决多层流程状态靠约定维护的问题，模型不可用也不影响报告数字。

• 基于 WebSocket 与自研句池归并实现实时语音转写，解决流式增量包乱序与供应商整句自我纠错导致的文本错乱问题，实测开口 0.56 秒出首字、停止说话 1.1 秒出终稿。

• 采用 Redis 跨实例单飞与题级锁消除多副本下同一请求重复打到模型的计费浪费，实例被 kill 后 260 毫秒由另一实例接管，会话状态与冻结报告逐字段一致。

• 采用 React 19 与后端 OpenAPI 生成的类型独立交付全栈前端，解决语音答题实时上屏与流式渲染的问题，175 例测试全绿、真实浏览器三轮手测通过。
