# 设计参照图说明

本目录存放 better-resume 界面的三张设计参照图（`sample-sidebar.png`、`sample-mock-interview-page.png`、`sample-resumes-page.png`）与本说明。

**定位：参照物非验收证据。** 三张图是设计参照物，供实现与评审对照版式、层级、配色与文案结构；验收以可复跑的命令和实拍/实现产物为准，参照图不参与判定。

## 逐张参照点

### sample-sidebar.png —— 侧边栏骨架

约 280px 宽的侧栏观感，自上而下分四段：品牌区、主导航、次级组、账号行。

- 品牌区：logo 标记 + 产品名，右侧收起图标。
- 主导航：图标 + 文字的条目列表，当前项以圆角高亮块标记。
- 次级组：与主导航之间用分隔线隔开，供辅助入口使用。
- 账号行：头像 + 账号名，右侧齿轮图标。

### sample-mock-interview-page.png —— 模拟面试页骨架

页头 + 主按钮 + 居中空态三步说明 + 底部主按钮。

- 页头：页面标题 + 一行副标题。
- 主按钮：紧贴页头下方的页级操作按钮，前缀 `+` 图标。
- 居中空态：插画、一句引导语，以及编号三步说明（选择简历 / 开始模拟 / 生成报告），每步为图标 + 标题 + 一行说明。
- 底部主按钮：空态末尾再放一次与页级同形的按钮。
- 按钮形态：暖黄实心、圆角，文字与图标同色。

### sample-resumes-page.png —— 我的简历页骨架

页头 + 导入按钮 + 空态图标/文案/按钮。

- 页头：页面标题。
- 导入按钮：页头下方的页级按钮，图标为上传符号。
- 居中空态：文档图标、「暂无简历文件」文案，以及一个主导入按钮。

## 当前生效的取舍清单（按用户裁定）

- 侧栏项：
  - 主导航：面试辅助、定制知识库、模拟面试、我的简历。
  - 次级组：用户手册、最新更新。
- 不采纳：样例里的「笔试辅助」「分享有礼」，以及「点数余额/特惠充值」卡片。
- 入口映射：
  - 对话 = 右下角圆形气泡按钮。
  - AI 设置 = 账号行齿轮。
  - 「我的简历」独立页；简历库功能未实现，导入按钮进「敬请期待」占位页。
  - 「模拟面试」承载现有面试流程（创建 → 面试间 → 报告）。
- 未实现功能一律进「敬请期待」占位页。

## 素材口径

logo 标记与插画为项目内 SVG 近似，不引外部素材。
