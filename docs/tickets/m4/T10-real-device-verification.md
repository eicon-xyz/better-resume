# M4-T10 — 真机验证（讯飞凭据 + 真实麦克风 + 真实 edge-tts）

- blocking：M4-T2 T4 T8
- 纪律：**没有凭据就不写"已验证"**；所有结论必须附命令输出

## 目标

把 T2/T4/T8 的代码路径在真实供应商与真实浏览器上跑一遍，产出可复核的真机证据；
跑不了的部分如实标注"未验证"并写清缺什么。

## 交付物

- 凭据接入：`BR_XUNFEI_APP_ID` / `BR_XUNFEI_ACCESS_KEY_ID` / `BR_XUNFEI_ACCESS_KEY_SECRET`
  （只在 gitignored `.env`；`.env.example` 只写变量名）
- `uv run python scripts/media_smoke.py`：真连讯飞 AST，喂一段真实中文语音的 PCM（或本地 wav），
  打印事件序列与最终三级文本；同时跑一次真 edge-tts 合成（字节数/时长/音色）
- 浏览器人工验证清单（写进 ACCEPTANCE）：
  1. 面试房间点麦克风 → 说一句中文 → 1s 内上屏 → 停止 → 提交后分数正常
  2. 点"朗读题目" → 听到播报；播放中切题 → 自动停
  3. 拒绝麦克风权限 → 提示正确，可继续用键盘答题
  4. 对话页语音输入 → 转写进输入框 → 发送得到回答
- `docs/tickets/m4/ACCEPTANCE.md` 里单列"真机验证"章节（含未验证项与原因）

## 测试

| 用例 | 断言 |
| --- | --- |
| 真 AST 建连 | 握手成功、无 4xx/5xx；签名被接受 |
| 真转写 | 一段中文语音 → committed 文本与语音内容一致（人工比对，记录原文） |
| 真 TTS | 生成 mp3，`file` 识别为 MPEG 音频、时长合理（±20%） |
| 浏览器四项 | 逐条打勾 + 截图/日志路径 |
