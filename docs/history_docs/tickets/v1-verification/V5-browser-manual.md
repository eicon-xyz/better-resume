## 操作清单（草案，确认后细化）

1. 打开 `http://127.0.0.1:8080/`，登录 → 进入面试页，允许麦克风权限；
2. 按住说话 10 秒念一段中文，**同时**在输入框里手打一句话；
3. 松手后观察：转写是否成句、是否**没有**覆盖你手打的内容、是否有 final；
4. 点击播报：音频是否播放、是否与文本一致、再点一次是否变停止（单例播放器）。

## 判定标准

| 步骤 | 通过条件 | 失败要记什么 |
| --- | --- | --- |
| 1 权限 | 页面提示已授权，WS 101 | 浏览器控制台报错原文 |
| 2 共存 | 手打内容一字不改 | 被覆盖的差异片段 |
| 3 转写 | ≥1 句可读中文，时间戳单调 | 原始 `cn.st`/事件序列（可从网络面板复制） |
| 4 播放 | 播放/停止可控，无重复播放 | 控制台报错与 `<audio>` 状态 |

## 不做

- 不做 Safari/Firefox 全兼容矩阵（默认只验你日常用的那一个浏览器）；不做移动端。
